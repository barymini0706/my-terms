商店販賣系統（消費者／客戶端）

程式名稱商店販賣系統(消費者(客戶)端)
條款版本1.0
甲方（程式創作者）余浡睿
生效日期2026/8/14（週五）

01第一條　定義

  1. 甲方：本程式之創作者及授權提供者。
  2. 乙方：取得本程式使用權限之使用者。
  3. 本程式：由甲方自行開發、製作及維護之程式及其相關內容。
  4. 金鑰：由甲方提供，用於驗證乙方使用權限之授權碼或其他驗證資訊。

02第二條　程式使用原則

  1. 甲方得提供乙方使用本程式之權利。
  2. 乙方取得之僅為本程式之使用權，不代表乙方取得本程式之著作權或其他智慧財產權。
  3. 未經甲方授權，乙方不得將本程式提供、轉讓、出租、轉售或散布予第三人。
  4. 乙方不得將甲方提供之金鑰轉讓、轉售、公開或提供予未經授權之第三人使用。
  5. 甲方得依實際情況決定是否向乙方提供金鑰。

03第三條　程式修改與改作

  1. 未經甲方明確授權，乙方不得修改、改作、重製、重新包裝或以其他方式變更本程式。
  2. 乙方不得將未經甲方授權修改後之本程式提供或散布予第三人。
  3. 如乙方對本程式進行未經授權之修改，甲方得停止提供相關技術支援、更新或售後服務。

04第四條　隱私與資料處理

  1. 本程式可能需要使用瀏覽器功能，以提供程式正常運作所需之功能。
  2. 本程式不會主動蒐集乙方之個人資料或其他使用者資料。
  3. 本程式不會主動將乙方導向未經說明之外部網站。
  4. 本程式只會導向本使用條款文件。如發生導向至其他網站或文件之情形，請提高警覺，並確認程式是否遭到未經授權之修改。

05第五條　金鑰及授權資訊

  1. 本程式之金鑰及授權資訊由甲方管理及提供。
  2. 乙方不得以任何未經甲方授權之方式取得、提取、破解、查看、使用或散布本程式內部未公開之金鑰或授權資訊。
  3. 乙方不得透過修改程式、破解程式或其他方式取得原本需要向甲方取得之授權金鑰。
  4. 如發現未經授權取得、使用或散布金鑰之情形，甲方得停止相關金鑰之使用權限，並視實際情況採取適當措施。

06第六條　條款同意

  1. 乙方於首次使用本程式時，應閱讀本條款。
  2. 乙方選擇「同意」後，始得依本條款使用本程式。
  3. 如乙方選擇「不同意」，本程式將停止提供互動及其他主要功能。
  4. 乙方如不同意本條款，不得繼續使用本程式。

07第七條　違規處理

  1. 如乙方違反本條款，甲方得依違規情況停止提供程式使用權限、金鑰、更新或技術支援。
  2. 如涉及疑似侵害著作權或其他權利之情形，甲方得依適用法律採取適當措施。
  3. 本條款之任何內容均不得解釋為排除或限制法律所保障之權利。

08第八條　使用權終止

  1. 甲方得依實際情況終止乙方使用本程式之權利。
  2. 如乙方違反本條款，甲方得立即終止乙方之使用權限。
  3. 使用權終止後，乙方應停止使用本程式及相關金鑰。
  4. 使用權終止不影響甲方依法享有之著作權或其他權利。

09第九條　條款修改

  1. 甲方得因程式功能、法律規範或其他合理原因修改本條款。
  2. 如條款有重大變更，甲方應於適當情況下提示乙方重新閱讀相關內容。
  3. 乙方如不同意修改後之條款，應停止使用本程式。

10第十條　其他

  1. 本條款之目的為規範本程式之授權及使用方式。
  2. 本條款未規定之事項，依適用之法律規定處理。
  3. 如本條款部分內容依法無效，不影響其他條款之效力。
